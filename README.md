# GitHub Pages Verify Card

هذه نسخة جاهزة للنشر على GitHub Pages لصفحة التحقق الخاصة بالبطاقة.

## الملفات
- `index.html` : صفحة التحقق الرئيسية.
- `CNAME` : ملف اختياري للنطاق المخصص، عدّل السطر داخله أو احذفه إذا لم تستخدم دومينًا خاصًا.

## طريقة النشر
1. أنشئ مستودعًا عامًا جديدًا على GitHub. GitHub Pages يستضيف مواقع ثابتة مباشرة من ملفات HTML ويدعم المواقع من مستودع شخصي أو مشروع. [web:53][web:54]
2. ارفع الملفات إلى الفرع `main`.
3. من إعدادات المستودع افتح Pages وحدد النشر من الفرع `main` ومن جذر المشروع. GitHub Pages يبحث عن `index.html` كملف دخول للموقع. [web:50][web:54]
4. سيظهر لك رابط عام على صيغة `https://USERNAME.github.io/REPOSITORY/` أو إذا كان المستودع باسم `USERNAME.github.io` فسيكون على الجذر مباشرة. [web:42][web:53]
5. إذا لديك دومين خاص، أضفه من إعدادات Pages في خانة Custom domain، ثم اضبط DNS حسب نوع الدومين. GitHub Pages يدعم `www` والنطاق الفرعي والنطاق الرئيسي. [web:39][web:46]

## ملاحظات الدومين
- إذا استخدمت نطاقًا مخصصًا، عدّل ملف `CNAME` ليحتوي على الدومين النهائي فقط.
- لإعداد النطاق الرئيسي أو الفرعي تحتاج سجلات DNS مناسبة، وGitHub يشرح إضافة Custom domain من صفحة الإعدادات مباشرة. [web:26][web:46]
